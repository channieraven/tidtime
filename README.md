# tidtime (ติดทาม)

tidtime เป็นเครื่องมือออฟไลน์สำหรับเปรียบเทียบข้อมูลข้ามเวลา ตัวเปรียบเทียบจับคู่แถวตามคีย์ที่กำหนดและคำนวณผลต่างของฟิลด์ตัวเลข โดยพักแถวที่คีย์ว่างหรือซ้ำ

ส่วนขยายแรกคือแอปสำรวจแปลงป่าบน Windows เจ้าหน้าที่นำเข้า Excel สองรอบ ตรวจหลักฐาน และบันทึกผลบนเครื่องได้ ดู [คู่มือแอปแปลงป่า](tidtime/README.md)
