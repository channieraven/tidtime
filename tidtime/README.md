# คู่มือแอปติดทามบน Windows

เปิด PowerShell ที่ราก repository แล้วรัน

```powershell
cd .\tidtime
npm.cmd ci
npm.cmd start
```

## ใช้ข้อมูลของคุณบนเครื่อง

เลือก Excel รอบก่อนและรอบปัจจุบัน แล้วเลือกชีตของแต่ละไฟล์ ตารางที่รองรับใช้แถวแรกเป็นหัวคอลัมน์ ได้แก่ รหัสแปลง, ลำดับต้น, รหัสต้นไม้, ชนิดพันธุ์, ปีรอบสำรวจ (พ.ศ.), วันที่สำรวจ, ความสูง (ม.) และ ความโตโคนต้น RCD (ซม.) เพิ่มคอลัมน์หมายเหตุได้

ตรวจชื่อแปลง ปี และวันที่ แล้วกด **เริ่มเปรียบเทียบ** รอบในปีเดียวกันต้องมีวันที่สำรวจครบและแยกลำดับได้ เลือกจุดเพื่อดูหลักฐานและเลขแถวจากทั้งสองไฟล์ บันทึกผลตรวจและเปิดย้อนหลังจาก **งานที่บันทึก** งานอยู่ใน `%APPDATA%\tidtime\surveys`

## ลองตัวเปรียบเทียบด้วยสินค้าคงเหลือ

จากโฟลเดอร์ `tidtime` รัน `npm.cmd run samples` เพื่อดูผลใน Terminal ตัวอย่างเปรียบเทียบกระดาษ SKU เดิมสองครั้ง จำนวน 12 กล่องเหลือ 9 กล่อง ได้ผลต่าง −3

## ตรวจการทำงาน

- `npm.cmd test` ตรวจการจับคู่ ทศนิยม การนำเข้า Excel และประวัติผลตรวจ
- `npm.cmd run test:ui` ตรวจขั้นตอนผ่าน Electron โดยสร้างรายการอุปกรณ์ในโฟลเดอร์ชั่วคราว
- `npm.cmd run dist:win` สร้างตัวติดตั้ง Windows x64 ใน `dist\`
